# Heart-First Meal Planner

A medication-aware Mediterranean meal planner for a household living with heart disease. It's where my dietetics degree meets the build.

**[Live demo →](https://lisaesterhuizen0-wq.github.io/heart-meal-planner/)**

## What it does

- **Two people, one plan.** Each person gets the same week of meals with their own portions and their own daily target.
- **Today, Week and Journal views.** Today shows what to eat now, Week shows the full seven days, and Journal logs how each day went.
- **Built around the medication.** The plan is written around a beta-blocker. It eases into lower carbs over two to three weeks, says to salt food to taste in week one, rules out potassium supplements, and asks for the cardiologist to confirm the plan.
- **Private by default.** The journal is saved in the browser on the phone. There's no backend and no account.

## How it's built

One HTML file with plain JavaScript and CSS. No framework and no build step, hosted on GitHub Pages. It's designed mobile-first, because it gets used in the kitchen.

## Note

This is a portfolio demo. The names are anonymised (John and Jane are placeholders). It's a guide, not medical advice, and any real plan needs to be checked with a cardiologist or GP.
